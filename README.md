# Bayarış Tekne Turu

GitHub Pages için hazırlanmış statik site paketidir.

## Yayın adımları
1. Dosyaları GitHub deposuna yükleyin.
2. `Settings > Pages` menüsünden yayın klasörünü seçin.
3. Alan adınız varsa `CNAME` dosyası ekleyin.
4. `index.html` içindeki canonical, og:url ve sitemap alanlarını gerçek alan adıyla güncelleyin.

## SEO güncelleme listesi
- Title ve description alanlarını gerçek marka iletişimine göre son kez kontrol edin.
- Telefon, e-posta, konum ve WhatsApp linkini doğrulayın.
- Görselleri IMAGE-GUIDE.md dosyasına göre ekleyin.
